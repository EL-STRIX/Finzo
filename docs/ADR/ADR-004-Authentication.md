# ADR-004: Authentication

## Status
Approved

## Context
The Finzo Banking Management System requires a standardized approach to authentication.

## Decision
We will session-based auth with secure httponly cookies.

## Consequences
- **Positive:** Improved consistency, maintainability, and alignment with enterprise standards.
- **Negative:** Requires strict adherence by all engineering teams.
