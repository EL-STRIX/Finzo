# ADR-006: CSS Architecture

## Status
Approved

## Context
The Finzo Banking Management System requires a standardized approach to css architecture.

## Decision
We will utility-first css via tailwind and bem for custom components.

## Consequences
- **Positive:** Improved consistency, maintainability, and alignment with enterprise standards.
- **Negative:** Requires strict adherence by all engineering teams.
