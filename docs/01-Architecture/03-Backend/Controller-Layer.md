# Controller Layer

## Controller Layer
**Purpose**: Mediates between HTTP strings and PHP objects.
**Dependencies Allowed**: FormRequests, Services, ResponseBuilder.
**Dependencies Forbidden**: Repositories, Database.
**Lifecycle**: Instantiated by the Router, executes a single method, returns JSON.
