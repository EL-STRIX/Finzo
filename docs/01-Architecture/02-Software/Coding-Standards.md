# Coding Standards

## PSR-12 Compliance
The entire application strictly adheres to PSR-12.
- Namespaces mirror directory structure.
- StudlyCaps for Classes.
- camelCase for properties and methods.
- Explicit return types are heavily mandated.

## Security Standards
No inline concatenation of SQL queries is permitted under any circumstances.
