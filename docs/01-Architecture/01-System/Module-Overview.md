# Module Overview

## Modules
- **Admin**: Oversees branches, staff roles, system configuration.
- **Staff**: Manages end-user requests, account approvals.
- **User**: Drives core financial interaction (deposits, transfers).
- **Auth**: Issues tokens and validates cryptographic signatures.
