# Coding Standards

## Table of Contents
1. [PHP Standards](#php-standards)
2. [Formatting Guidelines](#formatting-guidelines)

## PHP Standards
- Must adhere entirely to **PSR-12**.
- Methods and Properties must have explicit visibility (`public`, `protected`, `private`).
- Return types must be explicitly declared (e.g., `: array`, `: void`).

## Formatting Guidelines
- 4 Spaces for indentation.
- Opening braces for classes/methods on the next line.
- Variables must use `$camelCase`.
