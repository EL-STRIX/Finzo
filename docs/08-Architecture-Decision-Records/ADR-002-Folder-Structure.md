# ADR-002: Folder Structure

## Status
Approved

## Context
The Finzo Banking Management System requires a standardized approach to folder structure.

## Decision
We will feature-based folder structure inside standard mvc.

## Consequences
- **Positive:** Improved consistency, maintainability, and alignment with enterprise standards.
- **Negative:** Requires strict adherence by all engineering teams.
