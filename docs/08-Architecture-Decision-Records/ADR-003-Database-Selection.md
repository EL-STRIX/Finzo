# ADR-003: Database Selection

## Status
Approved

## Context
The Finzo Banking Management System requires a standardized approach to database selection.

## Decision
We will mysql/mariadb for relational data integrity.

## Consequences
- **Positive:** Improved consistency, maintainability, and alignment with enterprise standards.
- **Negative:** Requires strict adherence by all engineering teams.
