# Glossary

Welcome to the Finzo Banking Management System Glossary.

- **ACID:** Atomicity, Consistency, Isolation, Durability. Standard for reliable database transactions.
- **ADR:** Architecture Decision Record. Documentation of significant architectural decisions.
- **CSP:** Content Security Policy. Prevents XSS attacks.
- **CSRF:** Cross-Site Request Forgery.
- **FEPS:** Finzo Enterprise Product Standards. Our single source of truth for design and engineering.
- **KYC:** Know Your Customer. Financial regulation process.
- **PRD:** Product Requirements Document.
- **PSR-4:** PHP-FIG standard for autoloading classes from file paths.
- **PSR-12:** PHP-FIG coding style standard.
- **RBAC:** Role-Based Access Control. Security paradigm for endpoints.
- **XSS:** Cross-Site Scripting.
