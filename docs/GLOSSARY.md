# Finzo Glossary

| Term | Definition |
|------|------------|
| **Clean Architecture** | The software design philosophy separating the application into Domain, Application, Presentation, and Infrastructure layers. |
| **DTO** | Data Transfer Object. An object used to encapsulate data and send it from one subsystem to another. |
| **KYC** | Know Your Customer. Documents uploaded by users (e.g. Passports) to verify identity before their account becomes `active`. |
| **ACID** | Atomicity, Consistency, Isolation, Durability. Properties of database transactions ensuring valid data despite errors or power failures. |
| **CSRF** | Cross-Site Request Forgery. Security attack mitigated by unique, session-bound tokens in all POST/PUT/DELETE forms and requests. |
