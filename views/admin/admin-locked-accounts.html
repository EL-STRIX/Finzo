How account locking works: If a user enters the wrong password 5 times within 24 hours, their account is automatically locked for security and added to this queue. Once an administrator generates a temporary password (valid for 24 hours) and sends it via email, the account is automatically removed from this list. To regain full access, the customer must log in with the temporary password and set a new one immediately.
