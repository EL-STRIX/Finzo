Privacy Policy

Finzo Banking Management System • Effective Date: April 2026

Finzo Banking Management System (“Finzo”, “we”, “our”, or “us”) values the privacy and security of user information. This Privacy Policy explains how user data is collected, stored, used, and protected while using the Finzo platform.

By accessing or using the Finzo Banking Management System, users agree to the terms outlined in this Privacy Policy.

1. Information We Collect

The system may collect the following information:

Personal Information

  • Full name
  • Email address
  • Phone number
  • Account details
  • Uploaded verification documents

Technical Information

  • IP address
  • Browser type
  • Device information
  • Login activity
  • Session information

Transaction Information

  • Banking transactions
  • Account activity
  • Payment records
  • Transaction history

2. How Information Is Used

Collected information is used to:

  • Manage user accounts
  • Process banking operations
  • Maintain transaction records
  • Improve system security
  • Prevent unauthorized access
  • Provide customer support
  • Monitor system activity
  • Improve platform performance

3. Data Security

Finzo implements security measures to protect user information, including:

  • Password hashing
  • Secure session management
  • Middleware authentication
  • Database validation
  • Role-based access control
  • Secure API handling

Although security measures are implemented, no online system can guarantee absolute security.

4. User Authentication

Users are responsible for maintaining the confidentiality of their login credentials.

Finzo is not responsible for unauthorized access caused by:

  • Weak passwords
  • Credential sharing
  • User negligence

5. Cookies & Sessions

The system may use:

  • Session cookies
  • Authentication tokens
  • Login sessions

These technologies help maintain secure user authentication and improve user experience.

6. Data Sharing

Finzo does not sell or rent personal user information.

User information may only be shared:

  • When required by law
  • For security investigations
  • For authorized administrative purposes

7. File Uploads

Users may upload documents for verification purposes.

Uploaded files:

  • Are validated before storage
  • Should not contain malicious content
  • May be removed if they violate system policies

8. User Responsibilities

Users must:

  • Provide accurate information
  • Use the platform legally
  • Avoid unauthorized access attempts
  • Maintain account confidentiality

9. Limitation of Liability

Finzo is developed for educational and project purposes. While security measures are implemented, the system should not be considered a licensed real-world banking institution.

10. Changes to This Policy

This Privacy Policy may be updated in the future to improve security, compliance, or system functionality.

Users are encouraged to review this page periodically.
